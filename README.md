# UN Peacekeepers 0.2.6 alpha

RimWorld 1.6.4871. Scheduled UN intervention uses current storyteller threat points (already wealth- and difficulty-dependent) × goodwill multiplier × configurable UN strength (25–500%, default 100%, 5% steps). No additional minimum or cap. Other mods, including Unlimited Threat Scale, may affect the underlying points or actual group generation. Only UN scheduled raids use this formula; aid and other faction raids unchanged. Mod settings are persistent. Goodwill thresholds: -80/-85/-90/-95/-100 => strength 1.5/2/3/4/5; interval 12/9/6/4/3 days. Interpolated between thresholds. First raid after one day, later due dates recalculated from last successful raid. Report shows estimated requested points. Existing save fields retained.

All equipment, graphics, sounds, prisoner monitoring, manufacturing authorization, communications and combat group definitions remain as in 0.2.5. No new quest generation. Source and build artifact lack binary textures and sounds; full distribution ZIP combines those unchanged assets with the compiled DLL. In-game tests required.
